于是有了 三个自研 OBS 插件

实时字幕、HDR 播放列表、电视台式自动播出 —— 都是直播时嫌工具不顺手，自己写的。 免费、三平台、本地运行。

三个插件，各管一件事

  • Stream Live Translate —— 外语直播实时出中文字幕
  • HDR Playlist Source —— 多条视频连播，走原生 HDR 管线
  • tv-obsbroadcast-scheduler —— 按节目单到点自动播出
查看不息软件 GitHub 主页

都在 GitHub 发布，下载解压就能用

每个插件的最新发行版都会打包好 Windows / macOS / Linux 三个平台。

  • 实时字幕插件：插件文件夹复制进 OBS 插件目录即可
  • HDR 播放列表源：把 bin 与 data 分别复制到 OBS 对应目录
  • 自动播出插件：在 OBS 工具 → 脚本里加载 lua 文件

具体步骤在 不息软件 页里写得比较细。
