Stream Live Translate

给直播画面加上实时中文字幕的 OBS 插件。从媒体源内部取音频，交给大模型流式翻译， 再把字幕叠加回画面 —— 外语发布会直播时尤其好用。

能力清单

它到底能做些什么

复制即用

插件文件夹复制进 OBS 插件目录，无需安装器；OBS 启动自动拉起引擎，退出自动回收。

OBS 内部取音频

音频滤镜直接捕获媒体源的声音，不受系统其它声音干扰，比系统环回干净得多。

跨平台

Windows、macOS（Apple Silicon）、Linux 三平台都有发布包，免安装拷贝即用。

侧边栏控制台

用 OBS 自带「自定义浏览器停靠部件」打开管理面板，填 Key、调样式不用切出 OBS。

流式翻译

WebSocket 流式接口，低延迟；中文直通不翻译，其它语种自动同传为中文。

VAD + 音乐检测

检测到静音或音乐就跳过该片段，省 token 也不污染字幕。

效果预览

字幕直接压在直播画面上

四步上手

装好到出字幕，四步

  1. 安装插件

    把插件文件夹复制进 OBS 插件目录，启动或重启 OBS。

  2. 挂音频滤镜

    右键要出字幕的源 → 滤镜 → 添加「实时字幕捕获」，告诉插件听哪个源。

  3. 填 API Key

    OBS 视图 → 停靠部件 → 自定义浏览器停靠部件，打开控制台填入 Key 保存（只存本地）。

  4. 加字幕源

    场景里添加浏览器源，URL 填字幕叠加地址，建议 1920×240，开播即可出字幕。

模型兼容性

哪些模型能用，哪些不能

插件需要能「实时接收流式音频、边听边返回字幕」的 Realtime 模型。判断标准就这么一条。

可用 云端 / 本地都能跑

  • 通义 Qwen Realtime 语音 同传 / ASR / Qwen-Audio，云端开箱即用
  • 智谱 GLM-Realtime OpenAI Realtime 兼容
  • OpenAI Realtime 官方实时接口
  • FunASR 流式识别 本地自部署，中文 / 粤语强，默认端口 10095
  • speech-to-speech 网关 本地部署，可换 Whisper / Parakeet / SenseVoice 后端

不可用 接上了也不会有字幕

  • 纯文本 / 纯视觉模型 无法接收实时音频
  • 纯语音合成（TTS） 只出不进，不产生字幕
  • HTTP 上传式 ASR 非实时，接上也不会有字幕
💡
想完全本地跑： 起一个能流式出字的 ASR（FunASR / faster-whisper / SenseVoice），再套一个 OpenAI-Realtime 兼容网关，插件选「本机部署 API」连上即可。换模型只改网关里的 STT 后端，插件侧不用动。
