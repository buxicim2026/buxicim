02 · HDR 播放列表

HDR Playlist Source

OBS 的「HDR 播放列表源」：把一串视频排队连续播放，走 OBS 原生 HDR 管线 （P010 / Rec.2100 PQ·HLG 直通），不做 8bit 降级。本地文件、整个文件夹、 网络流都能进列表。

  • 真 HDR 直通，保留 10bit HDR 帧；配置不满足时自动按 SDR 播放
  • 播放模式：顺序 / 循环 / 随机；播放列表支持文件、文件夹、网络地址
  • 网络流支持 HLS（.m3u8）、DASH（.mpd）、RTMP / RTSP / SRT
  • 交叉淡化、播放速度 50%–200%、去隔行与硬件解码
  • 低内存模式默认开启，4K HDR 下内存与显存占用约减半
  • 属性面板实时显示「现在播放视频参数」与「目前直播配置参数」

安装与前提

Windows 11（需管理员权限）：

bin → obs-studio\obs-plugins\64bit\
data → obs-studio\data\obs-plugins\HDR-Playlist-Source\

Linux 放 ~/.config/obs-studio/plugins/；macOS 放 ~/Library/Application Support/obs-studio/plugins/。 data 目录必须一并复制，缺了会导致交叉淡化退化为硬切。

真 HDR 输出前提： OBS 设置 → 高级里色彩格式选 P010、色彩空间选 Rec.2100 (PQ) 或 (HLG)、 色彩范围 Partial，编码器用 HEVC 10bit 或 AV1 10bit。

03 · 自动播出

tv-obsbroadcast-scheduler

电视台式自动播出插件：在 OBS 里只放一个普通媒体源，插件负责把一堆视频排成节目单， 像电视台一样到点自动硬切、播完自动接下一条，中间还能插播广告。 由「OBS Lua 脚本 + 本地 Rust 引擎 + 网页节目单编辑器」组成。

  • 顺序连续播出，前一条播完立刻硬切下一条
  • 导入视频时自动读出真实时长，不用手填
  • 6 种节目类型：正片 / 公益广告 / 频道 ID / 节目预告 / 宣传片 / 插播内容
  • 设定开播时间后自动排出每条播出时间，可提前排期
  • 电视台报时器：整点半点浮出报时，字体、位置、底板可调
  • 国家授时中心 NTP 对时；状态落盘，OBS 或引擎重启后接着排
  • 播出浮窗（浏览器源）：ON AIR 灯、当前节目、下一档、剩余时间

安装与上手

下载解压后保持下面结构（engine 必须与 lua 脚本同级）：

tv-obsbroadcast-scheduler\
├── tv_obsbroadcast_scheduler.lua
└── engine\
    └── tv-obsbroadcast-scheduler(.exe)

OBS 菜单 工具 → 脚本 → 「＋」， 选择 tv_obsbroadcast_scheduler.lua，脚本会自动拉起引擎（后台运行，不弹黑窗）。

场景里要有一个媒体源（不要用 VLC 视频源）， 再开启 OBS WebSocket，在脚本面板填端口与密码并 Test Connection， 之后在网页编辑器里排节目单即可。

前端是 OBS Lua 脚本而不是二进制 DLL，所以不会遇到 DLL 导出符号或 libobs ABI 不匹配导致加载失败的问题。

本地运行

都在本机跑，凭据与节目单只存本地配置文件，不上传服务器。
